Framework · Visualizer · Playground

Turn any code or anything into a visualization.

PritVis is a local visualization shell. Drop HTML + Python projects as zip files, scan them for suspicious code, and launch them from a clean, terminal-style project stack.

PritVis 是一个本地可视化外壳。将 HTML + Python 项目打包成 zip 放入，自动扫描可疑代码，从终端风格的项目栈中一键启动。

Everything you need to run visualizations locally.

A focused toolset for developers, data explorers, and creative coders who want a private, fast launcher for HTML+Python experiments.

为开发者、数据探索者和创意编码者打造的私有、快速启动器，用于运行 HTML + Python 实验项目。

Local HTTP Server

Runs on port 5026 with Python's standard library. No build tools, no dependencies.

基于 Python 标准库在 5026 端口运行。无需构建工具，零依赖。

Project Stack

Drop .zip files into vp/ and they appear in the left sidebar automatically.

将 .zip 放入 vp/，项目会自动出现在左侧边栏。

Security Scan

Static analysis of Python, JS and HTML before first load. Dangerous patterns require explicit trust.

首次加载前对 Python、JS、HTML 做静态分析，危险模式需显式信任。

Light / Dark Themes

Terminal-green aesthetic with monospace typography. Toggle instantly.

终端绿风格 + 等宽字体，支持一键切换浅色 / 深色主题。

JS Plugin System

Auto-load plugin/*.js files. Register hooks via window.PritVis.registerPlugin().

自动加载 plugin/*.js，通过 window.PritVis.registerPlugin() 注册钩子。

Zero External Dependencies

Pure Python + vanilla HTML/CSS/JS. Works offline and stays simple.

纯 Python + 原生 HTML/CSS/JS，离线可用，保持简洁。

Three steps to your first visualization.

No configuration files, no deployment pipeline. Just zip, scan, and run.

无需配置文件，无需部署流程。打包、扫描、运行。

Package your project

Create a zip with an index.html entry point and optional Python logic.

创建一个包含 index.html 入口和可选 Python 逻辑的 zip。

Drop it into vp/

Place the zip in the vp/ folder next to server.py.

将 zip 放到 server.py 旁边的 vp/ 文件夹。

Launch from the stack

Click the project in the left sidebar. PritVis scans it, then loads it in the viewer.

在左侧边栏点击项目，PritVis 扫描后加载到查看器。

Scan before you run.

PritVis performs local static analysis on every project. Suspicious code is surfaced, not hidden.

PritVis 对每个项目进行本地静态分析，可疑代码会被展示而不是隐藏。

Status Meaning Action
safe No suspicious patterns detected. Loads automatically.
warning Some sensitive APIs were found (e.g. fetch, localStorage). Review scan report, then trust.
dangerous Dangerous calls detected (eval, os.system, subprocess, etc.). Explicit trust required.

Extend with JavaScript plugins.

Drop a .js file into plugin/ and register it with the global PritVis API.

将 .js 文件放入 plugin/ 目录，通过全局 PritVis API 注册。

// plugin/example-plugin.js
window.PritVis.registerPlugin({
  id: 'my.plugin',
  name: 'My Plugin',
  init() { console.log('Plugin ready'); },
  onProjectLoad(project) { console.log(project.name); }
});
