# PritVis Design Context

## Target Audience
Developers, data explorers, and creative coders who want to turn arbitrary HTML+Python projects into runnable visualizations without setting up a separate server.

## Use Cases
1. Drop a `.zip` (HTML+Python) into `vp/` and see it appear in a project gallery.
2. Click a project to load it in an iframe.
3. Scan project code for suspicious patterns before execution.
4. Extend PritVis with JS plugins from `plugin/`.

## Brand Personality / Tone
- **Industrial terminal aesthetic**: monochrome surfaces, terminal-green accent, monospace typography.
- **Trustworthy but not corporate**: visible security status, clear feedback, no marketing fluff.
- **Developer-first**: dense information, keyboard-friendly, fast interactions.
- **Anti-AI-slop**: no blue-purple gradients, no generic rounded cards, no glassmorphism.

## Visual Direction
- **Themes**: dark (default) + light, switchable instantly.
- **Accent**: terminal green (`#22c55e` / `#16a34a`).
- **Typography**: monospace family throughout (JetBrains Mono → Consolas → monospace).
- **Surfaces**: subtle 1px borders, no heavy shadows, minimal radius (2-4px).
- **Motion**: fast state transitions (150-250ms), no bouncy easing.

## Differentiation
A local "visualization OS" shell: left launcher, right stage, status bar like a terminal, security badges like a package manager.
